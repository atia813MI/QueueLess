# Smart Hospital Queue Management System

## Project Overview
QueueLess is a desktop application developed to make hospital patient registration and queue management easier. It aims to reduce manual paperwork, simplify serial generation, and make the patient registration process more organized and efficient.

## Problem Statement
In hospitals, patient registration and serial management are often handled manually using paper, registers, and handwritten records. This process requires time and effort from receptionists, increases paperwork, and may lead to errors in maintaining patient information and serial numbers. Managing multiple patients and keeping track of their order can also become difficult. Therefore, a simple computerized system is needed to make patient registration, serial generation, and queue management easier, faster, and more organized while reducing manual paperwork.

## Objectives
- Reduce manual paperwork in hospital reception.
- Simplify patient registration.
- Generate and manage patient serial numbers.
- Organize patient information efficiently.
- Reduce manual errors in registration and serial management.
- Make the receptionist's work easier and more efficient.

## Technologies Used
- HTML
- CSS
- JavaScript
- Electron.js

## Main Features
- Patient registration
- Automatic serial number generation
- Patient queue management
- Organized patient information
- Desktop application interface

## How It Works
The receptionist enters the patient's information into the application. The system registers the patient and generates a serial number. The registered patients can be managed through the application, making the registration and serial management process easier and more organized.
